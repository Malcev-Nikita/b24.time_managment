Закоммитить все изменения в проекте.

Акцент от Никиты (может быть пустым): $ARGUMENTS

## 1. Разобраться, что изменилось

Выполни и прочитай:

- `git status --short` — что вообще затронуто;
- `git diff --stat HEAD` — объём по файлам;
- `git diff HEAD` — сами изменения (если очень большой, смотри по частям);
- `git log -5 --format=%B` — образец стиля последних сообщений.

Читай диффы, а не только имена файлов: сообщение пишется про смысл изменений.

Если менялся код в `src/` — прогони `npm run lint`. Ошибки линтера — сказать
Никите и не коммитить, пока он не решит.

## 2. Написать текст

- **по-русски**;
- первая строка — суть изменения для пользователя дашборда;
- если изменений несколько — пустая строка и список `- …`, по пункту на
  смысловое изменение (не по файлу);
- строки переносить примерно по 75 символов.

Нельзя: англоязычных префиксов `feat:`, `fix:`, списков по файлам, слов
«рефакторинг», «оптимизация» без объяснения, что это дало.

Ориентир:

> Задачи в работе в отчёте и подсказка на барах графика
>
> - в список добавлены задачи в статусе «Выполняется» с учётом времени,
>   где пользователь исполнитель или соисполнитель, даже без записей за период
> - при наведении на бар графика показывается период и время

Если изменения не про дашборд (например, только настройка Claude Code) —
пиши про то, что изменилось в работе.

Если Никита задал акцент через аргумент — веди сообщение от него.

## 3. Закоммитить

- `git add -A` — коммитим всё, включая `.claude/`. Проверь, что в индекс не
  попали `.env*`, `.next/`, `node_modules/` — если попали, остановись и скажи;
- `git commit` с составленным сообщением.

**Атрибуция.** Автор — из `git config`. Никаких `Co-Authored-By`,
`Generated with` и упоминаний Claude — ни в теле, ни в трейлерах.

**Не пушить, не создавать ветки и PR** — это делает Никита.

Если изменения на несколько несвязанных тем — предупредить, но без просьбы не
разбивать.

## 4. Отчитаться

Коротко: текст коммита, сколько файлов ушло. Если что-то выглядит попавшим
в коммит случайно — сказать отдельно.
